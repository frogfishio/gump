# Feedback policy

Copyright (C) 2026 Alexander R. Croft

Gump is developed as an author-controlled project. We welcome bug reports and
suggestions, but we do not accept external contributions.

## What is welcome

- Bug reports that explain what happened, what was expected, and how to
  reproduce the problem.
- Feature requests and product suggestions.
- Questions and reports about unclear documentation or behaviour.

Please submit these through GitHub Issues. Before reporting a security
vulnerability publicly, contact `info@frogfish.io` so it can be handled
privately.

## What is not accepted

Please do not submit pull requests, patches, code, tests, documentation,
designs, translations, assets, or other contributed material. Pull requests
will be closed without review or incorporation.

Issue reports and suggestions may describe desired behaviour or identify a
problem, but should not include an implementation intended for incorporation
into Gump. The project author may independently implement an idea or fix a
reported problem.

The public repository is provided under `AGPL-3.0-or-later`. Commercial
licensing is available separately from <https://frogfish.io>.
